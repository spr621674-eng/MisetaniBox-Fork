Тип проверки
HTTP GET — показывает точное время ответа в миллисекундах через сам сервер.
Пинг всегда идёт настоящим запросом через выбранный сервер (не просто «видит ли телефон интернет»), поэтому это надёжный показатель именно того, что сервер реально работает. Прямой TCP/ICMP-пинг к самому серверу (в обход прокси-протокола) в этой версии ядра недоступен — движок mihomo такого не отдаёт через свой API.

Автономность
РАБОТАЕТ САМО, БЕЗ УЧАСТИЯ ПОЛЬЗОВАТЕЛЯ
Чтобы «Автовключение по приложению» не отключалось само по себе, телефон должен разрешить приложению работать в фоне. Обычно это три шага в системных настройках: добавить в автозапуск, разрешить работу в фоновом режиме и отключить оптимизацию батареи именно для этого приложения. Кнопка ниже откроет нужный экран — но на разных прошивках это выглядит по-разному: где-то она сразу отключает оптимизацию, где-то переносит в раздел «Батарея», где там нужно вручную поставить «Без ограничений» и отдельно включить фоновый режим. Если после этого функция всё равно отключается сама — стоит донастроить всё то же самое вручную через Настройки телефона → Приложения → это приложение.
